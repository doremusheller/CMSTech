The workflow

Every change earns its way live.

01 / Request

Client instruction

A content or design request arrives in plain English from the person responsible for the site.

02 / Access

Microsoft Entra ID

Authorized clients sign in through the same secure Entra access pattern used across the platform.

03 / Select

SmartWeb targets

The operator chooses the page or controlled site section that should be updated.

04 / AI proposal

SmartWeb AI

The request is interpreted into a proposed revision while preserving the existing page and supporting assets.

05 / Preview

Visual workspace

Current and proposed states can be inspected before anything is treated as publish-ready.

06 / Approval

Human review

The authorized operator can refine, discard, or approve the proposed change.

07 / Publish

Controlled deployment

Approved website updates move through the configured publishing boundary with the decision and result recorded.

08 / Exceptions

Escalation and retry

Unclear requests, failed previews, or deployment issues return to human review with reminders and retries as needed.
